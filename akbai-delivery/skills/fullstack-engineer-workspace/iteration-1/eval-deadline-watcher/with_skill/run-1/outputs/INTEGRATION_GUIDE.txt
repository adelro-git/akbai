================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Cannot find module '@/lib/utils/zod-schemas/deadline'"
  → Make sure deadline-schemas.ts is placed at: lib/utils/zod-schemas/deadline.ts
  → Check that your tsconfig.json has "@/*" pointing to the project root

Issue: "Cannot find module 'date-fns-tz'"
  → Run: npm install date-fns-tz

Issue: Page shows "May problema sa pag-load"
  → Check browser console for errors
  → Verify Supabase auth is set up correctly
  → Check that migration was applied: SELECT * FROM bir_deadlines;

Issue: Color indicators not showing (all cards green)
  → Verify date-fns imports are correct
  → Clear .next build cache: rm -rf .next && npm run dev

Issue: Days remaining calculation wrong
  → Likely timezone issue — verify server is UTC and client uses Asia/Manila
  → Check DevTools: new Date() should show UTC time
