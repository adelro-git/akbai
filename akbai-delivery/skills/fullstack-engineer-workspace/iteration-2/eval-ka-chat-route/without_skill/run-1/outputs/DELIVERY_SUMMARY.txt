  - Daily spend cap: ₱500 (~$8.86 USD)
  - Graceful degradation (503 status, not error)
  - Prevents runaway costs
  - Resets at midnight Asia/Manila

✓ RETRY LOGIC
  - Exponential backoff (1s → 2s → 4s)
  - Max 3 retries (4 total attempts)
  - Jitter to prevent thundering herd
  - Only retries on transient errors (429, 5xx, 529)
  - Fails immediately on client errors (4xx except 429)

✓ COST TRACKING
  - Every call logged in Philippine centavos
  - Haiku: ~₱0.16/call (receipt OCR)

✓ CONVERSATION HISTORY

  - RLS secured (users see only their own)
  - Soft delete only (GDPR compliant, recoverable)

DATABASE REQUIREMENTS
================================================================================

CREATE TABLES (2 tables required):

1. ai_spend_log (Circuit breaker tracking)
   - id (UUID, primary key)
   - user_id (UUID, FK to auth.users)
   - cost_centavos (INTEGER)
   - model (TEXT: "claude-haiku-4-5-20251001" or "claude-sonnet-4-6")
   - created_at (TIMESTAMPTZ default NOW())
   - INDEX: (user_id, created_at DESC)
   - No RLS (admin-only table)

2. ka_conversations (Conversation history)
   - id (UUID, primary key)
   - user_id (UUID, FK to auth.users)
   - domain (TEXT default 'financial')
   - message (TEXT)
   - role (TEXT: 'user' or 'assistant')
   - model_used (TEXT nullable)
   - input_tokens (INTEGER nullable)
   - output_tokens (INTEGER nullable)
   - cost_centavos (INTEGER nullable)
   - created_at (TIMESTAMPTZ default NOW())
   - updated_at (TIMESTAMPTZ default NOW())
   - deleted_at (TIMESTAMPTZ nullable)
   - INDEX: (user_id, domain, created_at DESC) WHERE deleted_at IS NULL
   - TRIGGER: auto-update updated_at
   - RLS: Users read own, insert own, update own

See IMPLEMENTATION_NOTES.md for full SQL with triggers and RLS policies.
