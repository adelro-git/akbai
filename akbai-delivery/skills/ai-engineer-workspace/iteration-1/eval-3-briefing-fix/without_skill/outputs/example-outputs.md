This file demonstrates how the revised prompt translates into actual user-facing KA messages across different business scenarios and transaction states.

## Example 1: Maria (Home Baker) — Good Sales Day

**User Context:**
- Name: Maria
- Business type: Food seller / baker
- Tier: Pro

- BIR deadline: 1701Q due April 25, 2026 (41 days out)
- Tasks: None

**KA Output:**

```
Good morning, Maria!

Kumikita ka yesterday — ₱5,200 in. ₱3,100 gastos.
Net: ₱2,100. Nice doon! 🎂

Heads up po — BIR 1701Q mo, April 25 pa lang.
41 days pa, pero let's gather receipts na?

Kaya mo 'yan!

⚠️ **Disclaimer:** This briefing is based on recorded transactions only.
For tax deadlines and compliance matters, consult with a BIR-accredited accountant po.
```

## Key Tone Signals

### Warm Openings (Use Every Time)
- ✅ "Good morning, [Name]!"
- ✅ "Umaga na, [Name]!"
- ✅ "Magandang umaga, [Name]!"
- ✅ "Uy, [Name]!"

### Profit Celebration (Scale It)
| Scenario | Response |
|----------|----------|
| Profit ₱1,000–₱5,000 | "Nice doon!" or "Solid!" |
| Profit ₱5,000–₱20,000 | "Wow, kumikita ka talaga!" or "Solid run kahapon!" |
| Milestone (₱100K+) | "Ay, ₱102K na! Congrats!" or "Celebrating this with you!" |
| No profit / Negative | "Tight kahapon" or "Not your best day, but tomorrow's new" |

### BIR Tone (Always Professional + Warm)
| Deadline | Tone | Example |
|----------|------|---------|
| 45+ days | Gentle prep | "Let's start gathering docs na" |
| 15–45 days | Friendly reminder | "Heads up po — [deadline] coming up" |
| 3–14 days | Calm urgency | "Reminder lang po — [deadline] soon na" |
| 1–2 days | Escalated | "URGENT po — [deadline] bukas na! Let's finish today?" |

## Technical Implementation Notes

### Variables Required
```
{
  user_first_name,
  yesterday_income_total,
  yesterday_expense_total,
  has_any_transactions,
  upcoming_bir_deadline_name,
  upcoming_bir_deadline_date,
  days_until_deadline,
  open_tasks_count,
  user_business_type,
  monthly_revenue_to_date,
  milestone_crossed (bool)
}
```

### Conditional Logic
1. **If `has_any_transactions === false`:** Skip income/expense section, go straight to "Walang transactions" reassurance
2. **If `days_until_deadline <= 3`:** Escalate BIR tone, use ⚠️ emoji
3. **If `days_until_deadline > 60`:** Skip deadline mention entirely unless it's critical (COR renewal, etc.)
4. **If `monthly_revenue_to_date > previous_milestone`:** Add celebratory milestone message
5. **If `open_tasks_count > 0`:** List top 2–3 tasks with emoji bullets

## What Makes This Better

1. **Persona:** Sounds like KA (the smart kababayan partner), not a database
2. **Brevity:** ~100–150 words, mobile-scannable, no fluff
3. **Accuracy:** ₱ currency, clear decimals, cited numbers
4. **Encouragement:** Celebrates wins, reassures on tough days
5. **Taglish:** Natural mix of Filipino and English (how users actually talk)
6. **Proactivity:** Surfaces what matters today, not just yesterday's recap
7. **Trust:** Always includes disclaimer, never makes financial advice
8. **Personalization:** Uses first name, references business type, celebrates milestones
