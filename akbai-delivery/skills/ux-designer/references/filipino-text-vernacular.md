## 1. Vowel-Dropping Shortcuts

The most common Filipino texting pattern — drop vowels to type faster.

| Shortcut | Meaning | Example Usage |
|----------|---------|---------------|
| bkt | bakit (why) | "bkt ang mahal?" |
| kc / kse | kasi (because) | "kc wala akong resibo" |
| lng / lang | lang (only/just) | "isa lng po" |
| nman / nmn | naman (emphasis particle) | "okay nman po" |
| mgkno / mkno | magkano (how much) | "mgkno po yung cake?" |
| pwd / pwds / pwede | pwede (can/allowed) | "pwd po ba COD?" |
| dto | dito (here) | "dto lng po sa bahay" |
| dun | doon (there) | "dun sa branch nyo" |
| pki | paki (please) | "pki send po ng menu" |
| cnu / cno | sino (who) | "cnu po mag-deliver?" |
| nu / ano | ano (what) | "nu po yung available?" |
| san | saan (where) | "san po kayo located?" |
| pno / pano | paano (how) | "pno po mag-order?" |
| gsto / gusto | gusto (want) | "gsto ko po yung red" |
| tnong / tanong | tanong (ask/question) | "may tnong lng po ako" |
| slmat / salamat | salamat (thank you) | "slmat po!" |
| wla | wala (none/nothing) | "wla na po ibang size?" |
| mron / meron | meron (there is) | "mron pa po ba stock?" |
| gnun / ganun | ganoon (like that) | "ah gnun po ba?" |
| tlga / talaga | talaga (really) | "tlga po ba?" |

## 3. Filipino Online Selling & Business Shorthand

### Marketplace Terms

| Shortcut | Meaning | Context |
|----------|---------|---------|
| HM | how much | "HM po nito?" |
| LP | last price | "LP po?" = lowest/final price? |
| LF | looking for | "LF: 2-layer cake for Saturday" |
| avail | available / to purchase | "I'll avail po" = I'll buy |
| mine / akin | claiming an item | "Mine po!" (in live selling) |
| pass | not buying | "pass muna po" |
| PM | private message | "PM sent po" |
| SF | shipping fee | "magkano po SF?" |
| COD | cash on delivery | "pwd po COD?" |
| MOP | mode of payment | "anong MOP po?" |
| DOP | date of payment | "kelan po DOP?" |
| ETA | estimated time of arrival | "anong ETA po ng order?" |
| PO | pre-order | "PO ba ito or on-hand?" |
| OOS | out of stock | "OOS na po yan" |
| on-hand / OH | in stock | "on-hand po ba?" |
| cutoff | order deadline | "kelan po cutoff?" |
| batch | production/shipping group | "next batch po kelan?" |
| DP | down payment | "may DP po ba?" |
| full payment / FP | pay in full | "FP na po para sure" |
| ref / ref no. | reference number (GCash) | "eto po ref no. 1234567" |

### GCash & Payment Phrases

| Phrase | Meaning |
|--------|---------|
| "gcash na lang po" | I'll pay via GCash |
| "sent na po" | Payment has been sent |
| "pa-check po" | Please check (if payment received) |
| "pa-confirm po" | Please confirm receipt |
| "may bayad na po" | Already paid |
| "pa-reserve po" | Please reserve for me |
| "i-hold po" | Please hold my order |
| "kelan po ma-rreceive?" | When will I receive it? |

## 5. Jejemon / Jejenese Patterns

> Rare in MSME business context but Kai should not break if encountered.

### Letter Substitutions
| Pattern | Example | Meaning |
|---------|---------|---------|
| Z for S | "magandaZ" | magandas/maganda |
| X for KS | "thanx" | thanks |
| H insertion | "pHoUhZz" | po |
| PH for F | "phriend" | friend |

### Number Substitutions
| Pattern | Example | Meaning |
|---------|---------|---------|
| 3 for E | "h3llo" | hello |
| 1 for I | "h1" | hi |
| 4 for A | "k4s1" | kasi |

### Mixed Pattern
- "eOw pFoUhZz" = "hello po"
- "jEjEjE" = laughter
- Alternating caps: "hElLo Po"

**Kai response:** Treat as normal input. Understand intent, respond in proper Taglish. Never mock or comment on the style.

## 9. Kai Input Understanding Rules

### How Kai handles text shortcuts in conversation:

1. **Understand but don't mirror** — Kai reads "mgkno po" and responds "₱3,450 po ang price." Never respond in text speak.
2. **Never correct spelling** — No "Did you mean...?" for text shortcuts. Treat as normal.
3. **Match formality, not format** — If user texts casually ("G lang"), Kai responds warmly but in proper Taglish.
4. **Business terms stay English** — "HM", "COD", "SF", "avail" are standard marketplace vocabulary. Don't expand them.
5. **Emotional particles are tone cues** — "huhu" = frustrated (be gentle), "HAHAHA" = happy (be celebratory), "grabe" = strong reaction (acknowledge it).
6. **Po signals respect expectation** — If user uses "po", Kai should use "po" back. If user doesn't, Kai can be more casual.
7. **Jejemon is not mockable** — If someone types "eOw pHo", understand it and respond normally. No judgment.
8. **Address terms signal relationship** — "boss" = transactional, "ate/kuya" = respectful, "mars/bes" = friendly. Match the energy.
9. **GCash phrases are action cues** — "sent na po" = user thinks they paid, verify. "pa-check" = waiting for confirmation.
10. **Multiple shortcuts in one message is normal** — "pwd po ba COD dto lng po sa QC" is a completely normal message. Parse the intent, not the spelling.
