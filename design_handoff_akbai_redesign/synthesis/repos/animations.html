Kai animations

Animations applied to the Kai mark on home hero, chat header, and onboarding completion.

kai-bob

Home hero · Kai sitting mark · 4s ease-in-out infinite

@keyframes kai-bob {
  0%, 100% { transform: translateY(0) rotate(-0.5deg); }
  50%      { transform: translateY(-4px) rotate(0.5deg); }
}
/* 4s ease-in-out infinite */
∞ infinite · 4s
Effect: Gentle vertical bob with subtle rotation. Pre-cognitive warmth (Don Norman visceral layer). Use: Kai sitting mark on home hero. Always running unless reduced-motion. Pairs with subtle drop-shadow.

kai-breathe

Onboarding wizard · login · alternative to kai-bob · 4s

@keyframes kai-breathe {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.025); }
}
/* 4s ease-in-out infinite */
∞ infinite · 4s
Effect: Subtle scale-pulse, like breathing. Quieter than kai-bob. Open question: Use kai-bob on home (active app context) and kai-breathe on auth/onboarding (calm, anticipatory)?

Tile + card entries

One-shot entry animations on cards, tiles, and toast appearances. Tile press uses pandesal-squish.

pandesal-squish

Action tile press / button click · 0.4s ease-out one-shot

📷
Scan
@keyframes pandesal-squish {
  0%   { transform: scale(1); }
  40%  { transform: scale(0.97, 1.02); }
  100% { transform: scale(1); }
}
/* 0.4s ease-out — runs on click */
one-shot 0.4s · click tile to retrigger
Effect: Slight squish on press (like real bread or a button being pressed). Use: Every brand action tile + primary button. Replaces standard :active scale.

slide-up

Card entry · page mount · 0.4s cubic-bezier one-shot

Card sliding up from below
@keyframes slide-up {
  from { opacity: 0; transform: translateY(10px); }
  to   { opacity: 1; transform: translateY(0); }
}
/* 0.4s cubic-bezier(.2,.7,.2,1) both */
one-shot 0.4s · cards stagger by 50ms
Effect: Fade + 10px upward translate. Subtler than ADOPT-HANDOFF default. Use: Every card mount on page entry. Use stagger delays (50ms × index) for cascading reveal.

Ambient backgrounds

Continuous low-energy animations on background motifs. All gated on prefers-reduced-motion.

petal-drift

Home FloatingPetals · 14s linear infinite (per petal)

demo box (petals fall outside it in real use) 
@keyframes petal-drift {
  0%   { transform: translateY(-20px) translateX(0) rotate(0deg); opacity: 0; }
  10%  { opacity: 0.55; }
  50%  { transform: translateY(50vh) translateX(20px) rotate(180deg); opacity: 0.45; }
  100% { transform: translateY(110vh) translateX(-10px) rotate(360deg); opacity: 0; }
}
/* 14–22s linear infinite · randomized per petal */
∞ infinite · 14–22s · 6 petals on home
Effect: Each petal drifts top-to-bottom with horizontal sway + rotation. Randomized delay/duration per petal. Performance: transform + opacity only. Off-thread compositor. Note: 6 petals on home is the proposed default; 12 only on celebration burst.
