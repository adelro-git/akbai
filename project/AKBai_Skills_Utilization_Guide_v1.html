Foundation

How to Use This Guide

🧭

The Core Principle

Each skill is a specialized AI brain you summon for a specific job. The key is giving it the right context upfront so it doesn't waste your tokens asking clarifying questions. Think of each skill invocation as hiring a consultant for 30 minutes — brief them once, get the deliverable.
1

Identify the task type

Match your current task to one of the 5 categories: Engineering, Design, Marketing, Tools (docx/xlsx/pdf/pptx), or Plugin Management.

2

Find your phase in this guide

Each roadmap phase has a curated set of skills with exact prompts. Use the cheatsheet at the bottom for quick lookup.

3

Start a fresh session for major work

For any single-skill deep work session (building a feature, writing a doc, planning a campaign), start a new Claude conversation. Keeps tokens clean.

4

Invoke the skill, then paste your context

Say "use [skill name]" then immediately paste the relevant context block from the session templates in this guide.

5

Save outputs to your Project Documents folder

Every deliverable generated goes into /AKBai/Project Documents/. Reference documents become fuel for future skill sessions.

⚠️

Token Budget Rule (Claude Pro)

Never invoke more than 2 skills in the same conversation. Each skill loads ~2K–4K tokens of instructions. For a single deep-work session: open a new conversation, invoke ONE skill, complete the full task, save the output. Context switching mid-session burns tokens fast.

Step-by-Step: Building the AKBai Plugin

The end state: A local Cowork plugin that auto-loads AKBai's full stack context, role skills, and slash commands into every session — eliminating the need to re-explain your tech stack, personas, and conventions every time you open a new chat.
1

Phase 0B — Capture Patterns as You Build

After every significant decision, save a one-paragraph "pattern note" in a Notion doc: "When building Supabase RLS, I always do X." These become your SKILL.md reference files.

anthropic-skills:docx
2

Phase 1 End — Create First Custom Skills

Use skill-creator to build: ka-voice (Katuwang writing), akbai-builder (stack conventions + feature scaffolding), bir-logic (BIR calculation rules). These replace the long context blocks you keep re-pasting.

anthropic-skills:skill-creator cowork-plugin-management:cowork-plugin-customizer
3

Phase 2 — Build the Full Plugin Scaffold

Use create-cowork-plugin to generate the full plugin directory: commands/ (sprint-start, ship, incident, gtm-report), skills/ (architect, builder, reviewer, deploy-guard, support-drafter, gtm), references/ (stack-spec, persona-guide, bir-calendar).

cowork-plugin-management:create-cowork-plugin
4

Phase 3 — Publish as Local Plugin + Iterate

Install the plugin locally, test every skill and command in a real dev session, refine based on what wastes tokens vs. what accelerates work. This plugin becomes the most valuable engineering asset you build alongside the product itself.

Expected Plugin ROI

Without the plugin, each new session costs ~500–800 tokens re-explaining your stack, personas, and conventions. With the plugin loaded, you start with full context in ~100 tokens. At 5 sessions per week over Phase 2–3, that's 170K–280K tokens saved per month — roughly 3–5 additional productive sessions per month on Claude Pro.
Token Budget

Token Efficiency Rules for Claude Pro

Rule Why It Matters Token Cost
One skill per conversation Each skill loads 2K–4K tokens of instructions. Two skills = 4K–8K gone before you start. HIGH if broken
Open new conversation for each major task Old conversation history accumulates. A 30-message thread has 8K–15K tokens of context you're paying to re-read on every new message. HIGH if ignored
Paste code, don't describe it Saying "my receipt scanner function" and then answering 3 clarifying questions wastes more tokens than just pasting the 40-line function upfront. MEDIUM
Use the sample prompts from this guide These prompts are pre-optimized to give Claude exactly the context it needs in one shot. Avoid freeform "can you help me with…" openers. LOW if followed
Save outputs immediately to /Project Documents/ Never re-generate something you already have. Reference it by pasting the relevant section, not by asking Claude to recreate it. LOW if disciplined
Build custom skills for patterns you repeat 3+ times A custom skill replaces a 300-word context block with a 10-word trigger. After 10 sessions, you've saved 5K+ tokens. VERY LOW at scale
Keep document sharing tight Don't paste the entire 61-page roadmap into a session. Paste only the 1–2 relevant sections. The roadmap has already been read — reference it by section name. HIGH if violated
Use lightweight skills for quick checks engineering:standup and marketing:brand-voice are lightweight. Use them freely. engineering:system-design and engineering:testing-strategy are heavy — save for real architectural sessions. VARIES by skill
